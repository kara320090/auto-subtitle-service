# 개발 계획

## 1단계: 기본 백엔드 구조 구성
- GitHub 작업공간 생성
- backend / frontend / data / docs 구조 생성
- FastAPI 기본 서버 구성
- health check API 작성

## 2단계: 영상 업로드 기능 구현
- 업로드 API 작성
- 파일 확장자 검증
- 업로드 파일 저장 로직 구현

## 3단계: 오디오 추출 기능 구현
- FFmpeg 설치 및 동작 확인
- 영상에서 wav 추출 기능 구현
- 오디오 저장 경로 정리

## 4단계: Whisper 전사 기능 구현
- Whisper 설치
- wav 파일 입력 기반 전사 처리
- 전사 결과(JSON, segments) 반환

## 5단계: 자막 생성 기능 구현
- segments 기반 SRT 포맷 변환
- SRT 파일 저장
- 자막 내용 검증

## 6단계: 자막 입힌 영상 생성
- FFmpeg subtitles 필터 적용
- 결과 mp4 저장
- 렌더링 결과 확인

## 7단계: 통합 처리 API 작성
- 업로드부터 렌더링까지 한 번에 수행하는 API 작성
- 다운로드 URL 포함 응답 구조 정리

## 8단계: 다운로드 API 작성
- SRT 다운로드 API
- 최종 mp4 다운로드 API

## 9단계: 백엔드 정리 작업
- 테스트 코드 작성
- FFmpeg 유틸 분리
- 스크립트 정리
- 문서화

## 10단계: 추후 확장 기능
- 도메인 분류 및 도메인별 보정
- 결과 메타데이터 저장
- 상태 관리(Job ID)
- 프론트엔드 UI 연결
